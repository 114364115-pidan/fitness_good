# 🌿 Quiet Fit — 質感微可視化健身追蹤器

一款輕量、低認知負擔、專注於「微可視化」的手機優先健身打卡 Web 應用程式。使用者可以根據自己收藏的部位訓練影片進行打卡，追蹤每週肌群平衡度，並透過極簡優雅的月曆三色圓點（運動、飲食、飲水）檢視日常累積的自律成果。

---

## ✨ 核心設計哲學

- **清透質感生活風（Minimalist Slate & Sage）**：以燕麥白（Slate 50）為基底，搭配純白卡片與鼠尾草綠（Emerald）、晨曦藍（Sky）、暖日光黃（Amber）點綴，去除多餘的視覺雜訊與沉重的黑鐵健身感。
- **低調安靜的成就感（Quiet Feedback）**：不使用誇張刺眼的彈跳動畫，而是透過細緻的邊框微光（Subtle Glow）、平滑色彩過渡與觸覺微震動回饋，提供沉穩自律的正向體驗。
- **手機優先（Mobile-First）**：排版針對單手握持與日常滑動操作最佳化，桌面端維持 `max-w-md` 精緻 App 視窗體驗。

---

## 🚀 核心功能特色

### 1. 每日專注提醒 (Daily Focus Modal)
- 每日首次開啟（或點擊頂部閃爍小圖標）自動展開專注提醒彈窗。
- 顯示當日日期、專注標語、0/3 維度完成進度摘要與預排訓練影片預覽。
- 支援「開始今日訓練」（自動滾動至打卡區）與「稍後提醒」（當次 Session 不重複干擾）。

### 2. 週肌群平衡指標 (Weekly Muscle Group Balance)
- **計算週期**：自動計算所選日期所屬該週（週一 00:00 至週日 23:59）的累積紀錄。
- **五大肌群追蹤**：`胸 (Chest)`、`背 (Back)`、`腿 (Legs)`、`肩臂 (Arms)`、`核心 (Core)`。
- 當週有完成該部位任一影片即點亮綠色膠囊標籤；全數達成時觸發「Quiet Balance Achieved」成就徽章與微光外框。

### 3. 精緻月曆可視化與 Perfect Day (Calendar View)
- **標準 7 欄制月曆**：支援上下月份切換、日期點擊歷史回顧與一鍵返回今日。
- **三色微型指示燈（3-Dot Matrix）**：
  - 🟢 **綠點**：運動部位打卡完成
  - 🟡 **黃點**：飲食檢核清單全數完成
  - 🔵 **藍點**：飲水目標達標
- **Perfect Day（完美日）**：當天三項皆完成時，日期格子呈現淡薄荷綠底色（`#F0FDF4`）與翡翠綠微光外框（`#10B981`）。

### 4. 部位訓練與影片打卡 (Workout Tracking)
- 支援肌肉部位橫向篩選（全部、胸、背、腿、肩臂、核心、全身有氧）。
- 整合外部影片連結（新分頁直達 YouTube / Bilibili），打卡不中斷。
- 內建完整的影片管理功能，可自由新增、編輯與刪除自訂影片。

### 5. 飲食與水分習慣追蹤 (Diet & Water Tracking)
- **飲食自律清單**：預設蛋白質、戒含糖飲與深綠蔬菜檢核項目，支援自由新增與刪除原則；清單全數勾選即判定完成。
- **水分追蹤**：自訂每日飲水目標（預設 2000 ml），提供直覺的一鍵達標切換按鈕。

## 🛠️ 技術選型與架構

本專案採**純前端零依賴架構（Zero-build & Single-file）**，開箱即用：

| 項目 | 技術方案 | 說明 |
| :--- | :--- | :--- |
| **結構與排版** | HTML5 + Tailwind CSS (Play CDN) | 輕量且易於維護，保證載入極速 |
| **圖標庫** | Lucide Icons (Vanilla CDN) | 簡約、細線條質感向量圖標 |
| **程式邏輯** | 原生 JavaScript (ES6+ Vanilla JS) | 無前端框架相依，極小化記憶體佔用 |
| **資料持久化** | Web Storage API (`localStorage`) | 離線友善，重新整理或關閉分頁不遺失紀錄 |
| **檔案結構** | 單一檔案 `index.html` | 免安裝 Node.js、npm 或建置工具 |
